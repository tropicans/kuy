# Plan 02-01: Zero-Anxiety Guided Stepper, Interactive Checklist & Barometer

## Goal
Menggantikan scrollytelling image generator dengan Interactive Guided Training Studio:
1. Stepper interaktif modul langkah-demi-langkah dengan visual status `[BELUM]`, `[SEDANG BERJALAN]`, `[TERVERIFIKASI ✓]`.
2. One-click copy engine dengan toast feedback visual "Tersalin ke Clipboard!".
3. Interactive checklist dengan persistent state di `localStorage` (`learnwith_checkpoints`).
4. Barometer Kesiapan Pelatihan Real-time yang mengalkulasi persentase penyelesaian modul.

## Requirements
- GUIDE-01: Step-by-step interactive workflow viewer with zero-anxiety reassurance
- GUIDE-02: 1-click copy engine with visual toast feedback
- CHECK-01: Interactive checklist with persistent localStorage state
- CHECK-02: Real-time readiness barometer calculating completion percentage
