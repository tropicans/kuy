# Plan 03-01: Automated Evaluation Quiz & Constructive Feedback

## Goal
Menambahkan sistem kuis evaluasi pemahaman di akhir modul praktikum:
1. Evaluasi checkpoint dengan multiple choice pertanyaan teknis praktis.
2. Penilaian instan (*immediate scoring*) tanpa penalti/beban cemas (*zero-anxiety constructive feedback*).
3. Penjelasan edukatif saat jawaban keliru agar peserta langsung paham letak pembetulannya.
4. Status kelulusan kuis yang meng-unlock lencana kesiapan modul.

## Requirements
- EVAL-01: Automated quiz engine with immediate scoring
- EVAL-02: Zero-penalty constructive feedback explaining corrections

## Proposed Changes
1. [NEW] `src/components/ModuleQuiz.tsx`: Komponen kuis interaktif yang menampilkan pertanyaan, opsi jawaban, visual status benar/salah, dan kotak penjelasan solutif.
2. [MODIFY] `src/components/TrainingStudio.tsx`: Mengintegrasikan `ModuleQuiz` di bagian bawah walkthrough atau sebagai tab evaluasi akhir modul.
