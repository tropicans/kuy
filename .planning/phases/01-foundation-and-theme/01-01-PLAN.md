# Plan 01-01: Multi-Course Schema, Course Data & Dual-Theme Architecture

## Goal
Membangun fondasi data kurikulum multi-kursus (Word ASN & Agentic AI), Navigation Shell dengan Theme Context (Dark Luxury / Clean High-Contrast Light Mode), dan landing catalog switcher.

## Requirements
- FOUND-01: Multi-Course catalog data model with complete metadata
- FOUND-02: Course switcher and curriculum overview navigation
- THEME-01: Dual-mode theme system (Dark Luxury & Clean High-Contrast Light Mode)

## Proposed Changes
1. [NEW] `src/data/courses.ts`: Model data kursus (`CourseData`, `CourseModule`, `CourseCheckpoint`), data lengkap Kursus 1 (Word ASN) dan Kursus 2 (Agentic AI).
2. [NEW] `src/context/ThemeContext.tsx`: React context untuk theme (`dark` vs `light`), persistent di `localStorage`, dan sinkronisasi class pada element root.
3. [NEW] `src/components/ThemeToggle.tsx`: Tombol switch tema yang elegan (Dark Luxury vs Clean High-Contrast).
4. [NEW] `src/components/CourseSwitcher.tsx`: Dropdown / pill switcher untuk berpindah antar kursus dengan visual indicator.
5. [NEW] `src/components/CourseCatalog.tsx`: Komponen bento/grid katalog kursus di halaman landing dengan kartu ringkasan kurikulum, modul, dan estimasi waktu.
6. [MODIFY] `src/app/layout.tsx`: Membungkus app dengan `ThemeProvider` dan penyesuaian CSS class agar responsif terhadap mode light/dark.
7. [MODIFY] `src/app/globals.css`: Penambahan variabel token light mode dan print styling dasar.

## Verification
- `npm run build` sukses tanpa error type.
- Toggle tema berfungsi mulus mengubah warna latar dan kontras teks.
- Katalog kursus menampilkan data Word ASN dan Agentic AI dengan navigasi interaktif.
